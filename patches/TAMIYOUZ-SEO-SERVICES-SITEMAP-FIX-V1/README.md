# TAMIYOUZ-SEO-SERVICES-SITEMAP-FIX-V1

Adds a dedicated WordPress sitemap provider for the 8 canonical Tamiyouz service URLs.

Expected:
- `/wp-sitemap.xml` contains the custom services sitemap
- `/wp-sitemap-tyzservices-1.xml` returns HTTP 200
- it contains exactly 8 service URLs

This does not alter DB content, theme, Elementor, or existing service pages.
