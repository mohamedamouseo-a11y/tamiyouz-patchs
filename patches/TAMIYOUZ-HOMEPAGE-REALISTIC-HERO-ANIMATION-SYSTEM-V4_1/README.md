- screen-local glass sweep / highlight
- local pointer response uses internal lighting only
- no physical-scene motion
- no whole-image tilt
- no photo parallax
- no detached overlay clones

- document.hidden guard
- reduced-motion disables continuous motion
- <=760px keeps V4 base static
