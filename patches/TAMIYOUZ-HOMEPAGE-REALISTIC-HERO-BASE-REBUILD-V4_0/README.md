This patch replaces the cartoon/native-vector workstation with the approved photorealistic entrepreneur workstation direction.

Architecture:
- one photorealistic physical-scene base asset: entrepreneur, chair, desk, monitor hardware, office, lighting
- the base image is STATIC and is never tilted or animated
- every important digital/UI surface is rebuilt as native DOM/CSS:
  - four top KPI cards
  - left monitor source/inbox surface
  - center analytics monitor
  - right workflow/team monitor
- native DOM surfaces are opaque and fully cover the baked UI inside their mapped screen areas
- screen glass/reflection layers sit above native UI so it reads as content INSIDE the hardware, not pasted over a picture
- all native components include stable data-* hooks for V4.1 animation
- V4.0 itself intentionally contains no continuous/heavy animation

Important:
This is the agreed hybrid photorealistic structure:
physical reality remains photographic; digital content is native and animation-ready.
No CSS/SVG person. No cartoon desk. No fake floating UI outside the mapped scene.
