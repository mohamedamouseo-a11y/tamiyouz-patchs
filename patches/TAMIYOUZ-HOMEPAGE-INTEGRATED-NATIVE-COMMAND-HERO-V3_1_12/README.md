Why:
The V3.1.11 screenshot proved the native direction was correct, but the composition was not:
- workflow cards floated above the scene
- the photo crop and native dashboard looked like separate collaged layers
- the command UI did not read as one premium product surface

V3.1.12 rebuilds the visual again as ONE integrated command scene:
- dark command deck on the left
- photographic person/workspace pane on the right
- workflow strip INSIDE the command deck
- source rail INSIDE the command deck
- KPI, bars, trend and automation status INSIDE the command deck
- no detached side panel
- no UI positioned over baked UI in the raster
- native DOM/CSS/SVG only for all animated UI
- raster used only for the static photo pane and mobile fallback

No DB changes.
No canonical commit/push.
